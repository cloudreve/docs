# 负载均衡 {#load-balance}

::: tip <Badge type="tip" text="Pro" />
本节介绍的是一个 Pro 版本特性。
:::

负载均衡存储策略是一种特殊的存储策略，它允许你将多个存储策略组合在一起，并根据负载均衡算法选择一个存储策略来存储文件。

## 配置 {#configure-load-balance-storage-policy}

1. 在后台管理面板 `存储策略` 中，创建多个用于负载均衡的存储策略。
2. 新建一个 `负载均衡` 类型的存储策略，并选择你要使用的子存储策略。
3. 保存后，你可以在详情页面配置各个子存储策略的权重：

   - 权重越大，被选择的概率越高。
   - 权重为 0 的子存储策略不会被选择。

   比如：存储策略 A 的权重为 1，存储策略 B 的权重为 2，存储策略 C 的权重为 0，那么存储策略 B 被选择的概率是存储策略 A 的两倍。

## 如何工作 {#how-it-works}

当使用负载均衡存储策略上传新文件时，Cloudreve 会根据各个子存储策略的权重来选择一个子存储策略来存储文件。文件的存储策略确定后，不会再自动切换到其他子存储策略。

要注意的是，负载均衡策略的实施由前端控制，用户仍然可以通过 API 自选子存储策略上传。
